# GitHub Profile Insights

A lightweight client-side integration with the GitHub REST API.

## What it does

- Accepts any public GitHub username
- Fetches live public profile data from `api.github.com`
- Shows public repository count, followers, and following
- Fetches recently updated public repositories
- Displays repository language and star count
- Uses no private credentials and requests no private repository data

## Run

Open `index.html` in a browser or use the GitHub Pages deployment for this repository.

## GitHub API

This project uses GitHub's public REST API endpoints for user profiles and public repositories. Requests are performed directly from the browser and are subject to GitHub's public API rate limits.

## Purpose

Built as a practical GitHub API integration project for developer tooling and portfolio use.
